# Apache Web Server Setup, Log Monitoring & Firewall Configuration

## Project Overview
This project demonstrates Apache web server deployment, HTTP log monitoring, and firewall configuration using Kali Linux.

## Tools Used
- Kali Linux
- Apache2
- UFW Firewall
- Linux Terminal
- HTML

## Project Implementation
1. Installed and configured Apache2 on Kali Linux.
2. Created and hosted a custom HTML webpage.
3. Tested web server access over the local network.
4. Examined Apache access logs to monitor HTTP requests.
5. Configured UFW firewall rules to allow and deny IP addresses.

## Skills Demonstrated
- Linux Administration
- Web Server Configuration
- HTTP Log Analysis
- Network Security
- Firewall Management
- IP-Based Access Control
